iOS Widget 資料匯出

匯出 Widget 資料 JSON，搭配 Scriptable App 在主畫面顯示信用卡權益摘要。

需要 Scriptable App
📋 Widget 設定步驟：
  1. 從 App Store 免費下載 Scriptable App
  2. 點擊下方「下載 Widget Script」取得 .js 腳本
  3. 用「檔案」App 將 CreditsPro.js 移到 iCloud Drive → Scriptable 資料夾
  4. 點擊「匯出 Widget 資料」，將 credits_widget.json 同樣存到 iCloud Drive → Scriptable 資料夾
  5. 長按主畫面 → + → Scriptable → 選擇 Medium 或 Large 尺寸
  6. 長按 Widget → 編輯 Widget → Script 選擇 CreditsPro
  7. 往後每次想更新 Widget，重複步驟 4 重新匯出即可
☁️

iCloud Drive 同步

將此 HTML 檔案儲存至 iCloud Drive，即可在所有 Apple 裝置上同步使用，資料自動保存於 localStorage。

需要 Safari / iOS
📋 iCloud Drive 使用方式：
  1. 點擊下方「下載 HTML 檔案」取得最新版本
  2. 在 iPhone / iPad：透過「檔案」App 將 HTML 移到 iCloud Drive
  3. 在 Mac：將 HTML 拖移到 Finder → iCloud Drive 資料夾
  4. 以後直接從 iCloud Drive 開啟該 HTML 檔案即可
  5. ⚠️ 注意：資料存於各裝置 localStorage，不同裝置需手動匯出/匯入 JSON 來同步
