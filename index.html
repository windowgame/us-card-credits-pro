iCloud Drive 同步

將此 HTML 檔案儲存至 iCloud Drive，即可在所有 Apple 裝置上同步使用，資料自動保存於 localStorage。

需要 Safari / iOS
📋 iCloud Drive 使用方式：
  1. 點擊下方「下載 HTML 檔案」取得最新版本
  2. 在 iPhone / iPad：透過「檔案」App 將 HTML 移到 iCloud Drive
  3. 在 Mac：將 HTML 拖移到 Finder → iCloud Drive 資料夾
  4. 以後直接從 iCloud Drive 開啟該 HTML 檔案即可
  5. ⚠️ 注意：資料存於各裝置 localStorage，不同裝置需手動匯出/匯入 JSON 來同步

將您的卡片紀錄下載為 JSON 備份檔，可跨裝置、跨瀏覽器還原。建議定期備份。
